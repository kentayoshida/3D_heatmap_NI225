# assets/ — 背景画像の差し替えスロット

宇宙背景の星空は既定では `public/js/space.js` が**プログラム生成**します（外部ファイル不要）。

ここに **`starfield.jpg`** を置くと、手続き生成の星空に代えてその画像を全天球（スカイ）背景に
使います。回転すると背景も立体的に動きます。

- **推奨形式**：equirectangular（**2:1** の正距円筒図法）画像。星雲帯なども継ぎ目なく巻けます。
- フラットな 16:9 等でも星は点なので概ね自然に見えますが、星雲帯は継ぎ目/極の歪みが出ることがあります。
- **著作権フリー（ロイヤリティフリー）**の画像を使用してください。
- ファイルが無い場合は自動的に手続き星空にフォールバックします（読み込み失敗も同様）。

## 惑星（`jupiter.jpg`）

惑星の表面も既定はプログラム生成（木星風の帯）です。**`jupiter.jpg`** を置くと、その画像を
球体に貼ります。

- **必ず equirectangular（正距円筒図法・2:1）の“世界地図”状マップ**を使ってください。
  丸い惑星の写真（円盤）は球面に歪んで貼られます（NASA 等の公開ドメイン木星マップが最適）。
- ファイルが無ければ手続き惑星にフォールバックします。

## 土星風の環（`rings.png`）

環も既定はプログラム生成（帯＋カッシーニの空隙＋透過）です。**`rings.png`** を置くと差し替えます。

- **横長の“帯（ラジアル断面）”ストリップ**を想定：画像の**左端＝環の内側、右端＝環の外側**。
  例：`saturnring` 系のリングテクスチャ。全体の円盤写真ではなく細長い帯を使ってください。
- **PNG のアルファ（透過）**が環の透け具合になります（すき間はアルファ0）。
- ファイルが無ければ手続きの環にフォールバックします。

## ローディング演出（ハイパースペース・3ファイル）

初回表示のデータ読込中（コールドスタート時は 20〜30 秒ほど）に、全画面で流す
**ハイパースペース航行**の演出です。読込完了の瞬間に**離脱クリップ**が再生され、短いフェードで
宇宙に浮かぶヒートマップが現れます。

**3フェーズを 3 つの独立ファイルで実装**します（`public/js/ui.js` の `createLoading`）。
1本の動画を途中でシークすると、断片化（fragmented）MP4 などでは**シークが不安定になり
冒頭へ戻る/静止する不具合**が起きるため、**クリップを物理的に分割**し、各ファイルは常に
自身の先頭から再生（cruise はネイティブ `loop`）＝**シーク一切なし**にしています。

| ファイル | 役割 | 再生 |
| --- | --- | --- |
| `hyperspace-entry.mp4`  | 突入 | 初回に**一度だけ**再生 |
| `hyperspace-cruise.mp4` | 航行 | 読込が終わるまで**ネイティブ `loop`** で反復 |
| `hyperspace-exit.mp4`   | 離脱 | **読込完了で**再生 → 末尾でフェードしてシーンへ |

順序：`entry`（1回）→ `cruise`（ループ）→（読込完了）→ `exit` → フェード。読込が速い場合は
entry を完走してから exit（cinematic）。

推奨仕様：

- **形式**：**H.264 の MP4**（互換性重視なら Baseline / Constrained Baseline）、**ミュート・
  音声トラックなし**推奨。3 本合計で**数MB以内**を目安に（720p/30fps 程度で十分）。
- **分割の作り方（例, ffmpeg）**：元の1本（entry/cruise/exit が連続した動画）から
  ```
  ffmpeg -i src.mp4 -t <entry終> -an -c:v libx264 -profile:v baseline -vf scale=1280:-2,fps=30 -crf 30 -movflags +faststart hyperspace-entry.mp4
  ffmpeg -i src.mp4 -ss <cruise始> -t <cruise長> -an … hyperspace-cruise.mp4
  ffmpeg -i src.mp4 -ss <exit始>            -an … hyperspace-exit.mp4
  ```
  cruise は始点＝終点の見えが近い区間にすると、ループのつなぎが自然になります。
- **著作権フリー（ロイヤリティフリー）**の映像を使用してください。
- 3 ファイルが無い/デコード不可の場合は、自動的に従来のスピナー表示にフォールバックします。

---

別名やパスを変えたい場合は `public/js/main.js` の `createSpace(scene, { assetUrl, planetUrl, ringUrl })`
の各 URL を変更してください。ハイパースペースのパスは `public/index.html` の
`#ld-entry / #ld-cruise / #ld-exit` 各 `<source src>` です。
